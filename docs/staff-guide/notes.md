Client notes are **staff-only**. Clients never see them. The same notes show up in several places, so an edit in one shows everywhere.

### Where to add a note

- **Work › Notes & SOPs → Notes** card (`#/work/notes`; it used to sit under Work › Tasks): pick a **Client** and a **Category** (General, Status, Handoff, Call or Meeting), type the note and click **Add note**.
- **+** → **New note** in the top bar on any client page. In ⌘K, **New note** with no client open goes to **Work › Notes & SOPs**.
- **Client details → Notes** (the client's **Client setup** gear → **Access and details** → **Client details**): a scratchpad for things like billing quirks or how a client likes to be contacted.
- **Client overview → Activity → Log a call**: saves a quick call note.
- **Client overview → Pinned notes**: pinned notes show here. **All notes** lists every note for the client, and you can edit or pin one without leaving the Overview. **Remove** isn't here: do that in **Client setup › Client details › Notes**.

### What you can do with a note

- **Pin** / **Unpin**: pinned notes show on the Client overview under **Pinned notes**.
- **Edit** or **Delete** (deleting can't be undone).
- **Make task**: turns the note into a private task, linked both ways. The note then shows the task's status, and the task shows on your My Tasks.

Use the **All clients** and **All categories** filters on the Notes card to find things.

### Handoff summary

The **handoff summary** is a special note: one per client, visible to every active staff member. Find it on **Work › Notes & SOPs → Handoff summaries** (`#/work/notes`). The card lists every client that has one, A to Z. Click **Edit** to change a summary, then **Save**. To write a first one, type the client's name in **Search clients** and click **Add a handoff summary for** that client. Keep it short and current, for example *"Waiting on March bank statement, flagged for QuickBooks migration."*

### Notes on transactions, budget lines and reports

For a note on one specific number, use the small note button right next to it. See [How do I leave a staff note on a transaction or report?](#/help/staff-notes).

> Never put passwords in notes. Write where the password is kept instead (for example, the password manager entry name).
