In **My Tasks**, a client's or project's list and a person's list, you can pick several tasks and change them together. Most changes, one task or many, also come with **Undo**.

### Select tasks

- Each task row has a small check box at its left, before the done box. It shows when you point at the row (on a touch screen it always shows). Tick it to select the task.
- On the keyboard, move to a row with **j** / **k** and press **v** to select it. **Shift+V** selects every task from the last one you picked to this one. **Shift-click** on a check box does the same.
- Selected rows are shaded, and a bar at the bottom of the page says how many you picked.
- **Esc**, or **Clear** in the bar, clears the selection. You can pick up to 100 tasks at a time.
- A task in a folded group stays selected while the group is folded.

The check boxes only show while you're online.

### What the bar can do

| Button | What it does |
|---|---|
| **Complete** | Marks the selected tasks done. A task that needs review goes to review instead, as it would if you ticked it. |
| **Reopen** | Shows when some selected tasks are done. Moves them back to **To do**. |
| **Reassign** | Pick a teammate to give them the tasks. They get the usual assignment email. |
| **Move to project** | Pick a project, or **No project**. A task never changes client this way. |
| **Due date** | **+1 day**, **+1 week**, **−1 day**, **No due date**, or **Pick a date…** for one date for all of them. |
| **Delete** | Asks *Delete N tasks?* first. Deleted tasks can be restored from the task's details, as before. |

### Some tasks are skipped, and the bar says so

Nothing is changed behind your back, and nothing is skipped silently.

- **Complete never approves anyone's work.** A task that is **Ready for review** or **Waiting on client** is left alone. Approve review tasks from **Tasks › Review**, and finish client requests from the task's details.
- Other reasons a task is skipped: it's already done (or not done, for Reopen), it was approved and only an admin can reopen it, only the person who made it or an admin can reassign or move it, the person you picked can't see its client, the project belongs to another client, it has no due date to move, or nothing would change.
- After the change, the bar shows *N skipped*. Click it to see why, grouped by reason, and click a task's name to open it. Click **×** to close the report.

### Undo

After you complete, reopen, reassign, move, reschedule or delete tasks (many, or one), the message at the bottom has **Undo** for 10 seconds. Press **Ctrl+Z** (**⌘Z** on a Mac) to do the same while the message shows. You'll see *Undone.*

- Ticking one task's done box, and deleting or reassigning one task from its details, can be undone the same way.
- Undo puts back what the action changed. A task someone changed in the meantime is left as it is, and the message says so.
- Undoing a done recurring task also removes the next copy it made, unless someone already worked on that copy.
- An assignment email that hasn't gone out yet is cancelled. One that already went is named in the message, so you can tell the person.
- If the message has gone, the change stays. *Too late to undo that one.* means the moment passed; change the tasks back by hand.

### Troubleshooting

- **I don't see the check boxes.** Point at a row, or check that you're online. On a very old browser tab, reload the page.
- **Complete is grayed out.** Everything you picked is already done, in review or waiting on a client.
- **"You can select up to 100 tasks at a time."** Act on these first, then pick the rest.
- **Ctrl+Z did nothing.** It only works while the Undo message is showing, and not while you're typing in a box (there it undoes your typing).
