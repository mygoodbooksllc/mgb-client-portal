You can pin a private note to a single bank transaction, budget line or report. Clients never see these notes.

### Add a staff note

1. Open the client and go to **Budget**, the bank transactions list, or **Reports**.
2. Find the small note icon next to the budget line, transaction description or report title. A number on it means notes already exist.
3. Click it. A small window opens titled **Staff notes** ("Clients never see these").
4. Type your note (for example *Asked Kelly about this on 9/12…*) and click **Add note**.

Each note shows who wrote it and when. You can **Delete** your own notes, but not other people's.

The latest five of these notes also show on the client's **Client overview**, under **Notes on transactions, budget lines and reports**.

### Record that you sent a report ("Mark sent to client")

On each report card on the **Reports** page, under **Download PDF**, there's a **Mark sent to client** link.

1. Send the report to the client the way you normally do (email, shared folder, etc.).
2. Click **Mark sent to client**. A **Sent {date}** pill appears; hover it to see the full history.
3. If it was already sent, you'll be asked to confirm another send (**Mark sent again**).

> **Mark sent to client only records the send. Nothing is emailed.** It feeds the **Sent to the client** card and the Activity timeline on Client overview.

### Troubleshooting

- **"Couldn't save that note."** Check your connection and try again.
- **I don't see the note icons.** They only show for staff, and not while you're using **Preview as** a client user.
