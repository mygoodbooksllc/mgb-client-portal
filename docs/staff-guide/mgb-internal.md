**MGB (internal)** is MyGoodBooks' own books, set up like a client so we can use our own tools on ourselves: the Client overview, Documents, Close, Ledger review, Reports, SOP and the rest. It's **not a client**, and no real-client number includes it.

### Who sees it

Only an admin who has been given the **MGB (internal)** permission. Everyone else never sees it, not even as a hint:

- Temporary admins, bookkeepers and account managers don't see it.
- Clients never see it.
- **View as** hides it too. While you preview someone, it's gone from the rail, the client picker and search, and its address won't open.

Every admin has the permission by default, including admins added or promoted later. The owner can switch it off for a person, and that stays off until the owner switches it on again.

### Open it

Click **MGB (internal)** in the left rail (under **Clients**). It opens like any client: the same tabs, with a small **Internal** tag by the name. The address `#/internal` also takes you there if you have the permission.

### Give or take away the permission (owner only)

1. Go to **HR → Members**.
2. In the **MGB (internal)** column, untick an admin to take the permission away, or tick them to give it back.

Only the owner sees that column. The change takes effect the next time that admin loads the page, and the server enforces it, so hiding the link isn't the only protection.

### What it never counts in

MGB (internal) is left out of everything that measures real clients, the same way the test clients are:

- Client lists and counts on **Clients**, **Today** and **Team**, and the client picker's totals.
- Deadline, close, overdue and late counts and alerts.
- Performance scores, celebrations and the weekly digest.
- Hours budgets, workload, fees, revenue, cost and profit.
- Client emails. It never receives them.

Emails about MGB (internal) tasks and messages (new task, due today, mentions) do not go to the people on the task. They all go to one address the owner sets, and nothing is sent until that address is set.

It does show in a few pickers (for example when you pick a client for a note), last in the list with its **Internal** tag, so you can still log work against it. Whether you see it there depends on the permission, not on **Show test clients**.
