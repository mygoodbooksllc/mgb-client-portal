On every client page, staff see a small bar labeled **Staff** at the top with five buttons. Clients never see it.

| Button | What it does |
|---|---|
| **Overview** | Opens the client's staff-only Client overview. |
| **Add task** | Adds a task for this client to My Tasks. |
| **Request document** | Asks the client to upload a file. |
| **Add note** | Saves a staff note on this client. |
| **Message** | Opens the chat drawer on this client's people. |

### Add task

Type the task (for example *Follow up on the missing receipts*), pick a **Due** date if you like and click **Add a task**. **Visible to everyone on this client** is ticked by default, so the other staff on this client can see it. Untick it to keep it private.

### Request document

Type **What you need** (for example *September bank statement*), a **Due** date and optional **Details**, then click **Request a document**. The client sees it on their Documents page and can upload straight into it. More in [How do I request a document from a client?](#/help/document-requests).

### Add note

Type the note and save. It's saved as a General staff note on this client.

### Troubleshooting

- **"Couldn't save that. Please try again."** Check your connection and try again. If it keeps happening, tell an admin.
- **I don't see the bar.** It's hidden while you're using **Preview as** to look at the portal as a client user.

The **+** button in the top bar opens the same **Add task**, **Add note** and **Request document** forms (as **New task**, **New note** and **Request document**). See [What's on the bar at the top of the page?](#/help/top-bar).
