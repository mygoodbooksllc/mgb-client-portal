Every new client has an **Onboarding** checklist. Admins find it at the bottom of the client's **Client overview**, in **Billing and time**. Bookkeepers, account managers and temporary admins don't see it. It shows **X of Y** steps done and a progress bar. Once every step is done it folds to one line (*Onboarding done · 5 of 5 · Organization type: Nonprofit*) with a **Show steps** button.

For the whole setup, from adding the client to their first sign-in, see [How do I set up a new client from start to finish?](#/help/new-client-start-to-finish).

### Organization type

Under the progress bar, choose **Organization type**: **Nonprofit** or **For-profit**. It saves as soon as you pick ("Marked as a nonprofit." / "Marked as a for-profit business."). Any staff member can also set it on the Overview, in **Key dates and coverage**. It's the same setting in both places. Admins can also set it when adding or editing a client on **Client roster** (**Settings → Firm settings**).

New clients start as **Nonprofit**. For now it's only stored. Later, estimated taxes and sales-tax features will apply to for-profit clients only, so set it correctly now.

### Payroll tab

A client only has a **Payroll** tab if **Payroll add-on** is ticked for them on **Client roster** (**Settings → Firm settings**). If they don't use our payroll, leave it unticked and the tab stays hidden.

### Tick off steps

- Tick each step's checkbox as you complete it. The card records who ticked it and when.
- Some steps tick themselves. They're marked **Auto: QuickBooks** or **Auto: Close tracker** (the close status on Work › Close) and can't be ticked by hand:
  - **Auto: QuickBooks** ticks when the client's QuickBooks is connected.
  - **Auto: Close tracker** ticks when the first month is saved, on Work › Close or on the client's Close tab.

Until every step is done, admins see an **Onboarding 3/5**-style badge on the client in the client picker. Other staff don't see the badge.

- **Hover** over the badge (or Tab to it) to see the checklist: done steps are ticked and grayed out, so what's left stands out.
- **Click** the badge (or press Enter on it) to open that client's **Client overview**. The page opens **Billing and time** if it was closed, scrolls to the Onboarding card and briefly outlines it in gold.

### Change the default steps (admins)

Admins see **Edit default steps** on the card. Every client gets these steps.

- Reorder with ↑ / ↓, rename a step, or add a **Short description (optional)**.
- Choose **Manual only**, **Auto: QuickBooks connected** or **Auto: first month closed**.
- Untick **Shown** to hide a step. Hiding keeps what's already been ticked.
- Add a new step (for example *Payroll set up*) with **Add step**.
- Changes save as you go. Click **Done** when finished.

### Troubleshooting

- **An Auto step hasn't ticked.** Check that QuickBooks is actually connected (Client details → QuickBooks), or that a month has been marked **Done** on Work › Close or the client's Close tab.
